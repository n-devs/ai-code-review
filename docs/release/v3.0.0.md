# v3.0.0

## What's changed

- **File-based agents** — agent definitions now live in markdown files (`agents/<name>.md`): `author`, `primary`, `specialist`, `checklist`, plus `combined`. The first line `# Label` is the display name; the rest is the persona. Customize by editing the files, or point `agents_path` at your own folder to override built-ins / add new agents.
- **Single combined agent by default** — with `agents` empty, the review runs as **one AI call** merging all four roles (author self-review + explanation, primary logic/edge-case/test checks, specialist security/architecture/DB checks, and a closing checklist table). Faster and cheaper; set `agents: all` or a comma-separated list to split into parallel role-focused agents.
- **Skills** — knowledge modules injected into every agent's prompt (`skills: auto | all | names`). Six built-ins (security, testing, performance, clean-code, error-handling, api-contract), plus `custom_skills` (JSON) and `skills_path` (import a folder of `*.md` files from your repo).
- **Web search (`web_search`)** — agents can look things up during review: native web search for Anthropic messages / OpenAI responses, and a `web_search` function-calling loop (DuckDuckGo, no API key) for chat / GitHub Models.
- **Thinking & effort** — `mode: thinking` and `effort: low|medium|high|max` map to `enable_thinking`/`reasoning_effort` (chat), `reasoning.effort` (responses), or a thinking budget (messages).
- **Agents talk to the code owner** — every report section and inline comment starts with the owner's username as a clickable profile link (no mention noise), and the AI is instructed to address the owner directly.
- **Parallel agents, unlimited inline comments** — agents run concurrently (capped at 5 in-flight AI calls); `max_comments` now defaults to **unlimited** (set a number for a round-robin quota across agents). The checklist summarizes as a table in the Conversation tab.
- **New providers** — `qwencloud` and `qwencloud-plan` (OpenAI-compatible and Anthropic-compatible endpoints).
- **Reliability hardening** — 5-minute request timeout per call, automatic retry on 429/5xx (3 attempts with backoff) for AI calls and GitHub GETs, paginated PR files API (up to 3000 files), numeric `pr_number` validation.
- **CI** — new `ci.yml` runs install + tests + build on every push/PR.

## Notes

- The default behavior changed: an empty `agents` input now runs the single combined agent instead of a plain generic review. Use `agents: all` for the multi-agent experience.
- Existing v2 workflows keep working — all new inputs are optional and default to safe values.
- Use `n-devs/ai-code-review@v3` (or `@v3.0.0`) to pin this release.
