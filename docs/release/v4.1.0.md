# v4.1.0

## What's changed

- **`memory_branch` input** — choose the branch where review memory is saved:
  - Empty (default) keeps saving to the repository's **default branch**, exactly as before.
  - Specify a branch (e.g. `memory_branch: cloud-pvt`) to save `<date>-context.md` there instead.
  - The branch must already exist — if it doesn't, saving is skipped with a warning and the review still completes normally.
  - Both reading the existing file (`?ref=`) and committing (`branch`) target the same branch, keeping file SHAs consistent.

## Notes

- Loading memory still follows the calling workflow's checkout (manual dispatch = default branch); `memory_branch` only controls the save destination. To also load from that branch, point the workflow's checkout at it.
